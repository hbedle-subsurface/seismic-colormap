How colormaps actually work
Modules About AASPI

AASPI  ·  University of Oklahoma

A seismic attribute is a set of numbers. Every decision you make about it comes from a picture of those numbers.

Between the two sits a colormap and a value range. They decide which parts of the data separate into visible features and which are compressed into colors the eye cannot tell apart. Change either one and the same volume yields a different map, with nothing on the display to say so.

These modules open that up. Build a channel, break it with faults, add noise, then put the result through two colormaps at once at a value range you control, and watch which features survive. There is nothing to install.

What you need first. They are written for undergraduate geology and geophysics students. You should know what a seismic trace is and what a reflector is. No color science is assumed; that is what module 01 is for. Each attribute used here has a short explanation built into the modules, and a link out to the module set that covers it properly.

What you should be able to do afterwards. Say which class of colormap an attribute needs and why. Set a display range from the distribution rather than from the extremes. Tell a boundary that is in the data from one the display invented, in a few seconds, on any figure. Check whether a figure works for a reader with a color vision deficiency. And record a display so that somebody else can reproduce it.

About

Built for teaching by Dr. Heather Bedle and Dr. April Moreno-Ward, School of Geosciences, University of Oklahoma, with the Attribute Assisted Seismic Processing and Interpretation (AASPI) consortium.

Companion to How Geometric Attributes Actually Work, which covers what the attributes measure. This set covers what happens to them on the way to the screen. It follows Bedle and Moreno-Ward (2025), Techniques for improved visualization and interpretation of seismic attributes using scientific colormaps, Interpretation, 13, B25–B37, doi: 10.1190/INT-2025-0003.1, which works the same material on 3D seismic data from the Great South Basin, New Zealand.

The colormaps here are the published definitions rather than approximations: Crameri (2018) for Oslo, Roma, RomaO, Lajolla, Batlow and Vik; Thyng et al. (2016) for balance; Smith and van der Walt (2015) for Viridis. Rainbow, turbo, red-white-blue and a cyclic HSV map are included for comparison, because a comparison needs something to compare against.

Everything runs in the browser. No installation and no account. Nothing you do inside a module — no slider, no click, no trace you generate — is transmitted anywhere. The module code makes no network requests of its own.

The one request each page does make is a page-view count, which records that the page was opened and nothing else. No cookie is set and no identifier is stored, and nothing about what you did on the page is sent. We keep that count for two reasons — so the modules people actually use are the ones that get improved, and so we can show the university that you all are using these, which is how they keep getting built.
